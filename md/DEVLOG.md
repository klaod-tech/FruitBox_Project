# FruitBox 개발 로그

---

## 웹 버전 (docs/)

### 기반 구조
- Emscripten WASM 빌드 없이 브라우저에서 바로 동작하는 Mock 모드 구현
- `game_core.js` 로드 실패 시 자동으로 JS Mock 폴백
- GitHub Pages 배포 (`docs/` 폴더 기준)
- 로컬 실행: `python -m http.server 8080 --directory docs`

---

### 게임 로직

| 항목 | 내용 |
|------|------|
| 보드 | 10×17, 숫자 1~9 무작위 배치 |
| 제거 조건 | 드래그 영역 합 = **정확히 10** |
| 아이템 (보드) | 💣 폭탄(인접 4칸 제거), ⏱️ 시계(+5초) — 제거 시 10% 확률 스폰 |
| 아이템 (인벤토리) | 🔍 힌트 x2, 🔢 숫자변환 x2 |
| 제한 시간 | 120초 |

### 난이도 시스템

| 난이도 | 일시정지 |
|--------|---------|
| 쉬움 | 제한 없음 |
| 보통 | 최대 5회 / 1회당 10초 자동 재개 |
| 어려움 | 불가 |

---

### 기록 저장 (localStorage)

난이도별 최고 기록과 기기 고유 ID를 브라우저에 영구 저장.

| 키 | 내용 |
|----|------|
| `fruitbox_device_id` | UUID (최초 1회 생성) |
| `fruitbox_best_easy` | 쉬움 최고 기록 |
| `fruitbox_best_normal` | 보통 최고 기록 |
| `fruitbox_best_hard` | 어려움 최고 기록 |

> 추후 Supabase 연동으로 전체 랭킹 공유 예정 (`Store.syncToServer()`)

### 키보드 단축키

| 키 | 동작 |
|----|------|
| `P` | 일시정지 / 재개 |
| `Q` | 첫 화면으로 복귀 |
| `W` | 숫자 변환 아이템 사용 |
| `E` | 돋보기 아이템 사용 |
| `R` | 보드 재시작 (게임 중 언제든) |

---

### UI / 시각 개선

- 드래그 중 합계 실시간 표시 (합=10이면 초록, 0<합≠10이면 빨강)
- 제거된 칸도 드래그 시 노란 하이라이트로 선택 범위 표시
- HUD 버튼 테두리·너비·높이 통일 (힌트/변환/일시정지/리셋/홈)
- 일시정지 오버레이 제거 → 버튼 텍스트로 상태 표시 (`▶ 재개 (9s) [1/5]`)

---

### 버그 수정

| 수정 내용 | 설명 |
|----------|------|
| 게임오버 후 재시작 시 `pauseCount` 미초기화 | normal 난이도 일시정지 횟수가 누적되던 버그 |
| 제거 조건 `s % 10 === 0` → `s === 10` | 10의 배수(20, 30...)에서도 제거되던 버그 |
| 더블 아이템 제거 | C/웹 전 버전에서 삭제 |

## C 터미널 버전

### 구조

| 파일 | 역할 |
|------|------|
| `main.c` | 전역 변수, 타이머 스레드, 입력 루프 |
| `board.c` | 보드 생성, 합산 판정, 아이템 스폰 |
| `ui.c` | ncurses 렌더링, 마우스 이벤트 |
| `apple.h` | Apple 구조체, 전역 extern 선언 |

### 단축키

| 키 | 동작 |
|----|------|
| `p` | 일시정지 / 재개 |
| `e` | 돋보기 아이템 사용 |
| `w` | 숫자 변환 아이템 사용 |
| `q` | 게임 종료 |
| `r` | 재시작 (게임 오버 후) |

### 주요 변경

- 단축키 변경: `Q` → `e` (돋보기), `W` → `w` (숫자변환)
- HUD 표시 변경: `[Q:n]` → `[E:n]`
- 더블 아이템(`[x2]`) 제거: `ITYPE_DOUBLE` enum 및 관련 로직 삭제
- 스폰 확률 변경: BOMB/CLOCK 각 50%
