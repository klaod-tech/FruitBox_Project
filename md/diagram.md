# FruitBox 다이어그램 분류

알고리즘 19개를 흐름(Flow) 기준으로 5개 다이어그램으로 분류합니다.
각 다이어그램은 앞 단계의 결과가 다음 단계의 입력이 되는 연속된 흐름으로 구성됩니다.

---

## 다이어그램 1 — 게임 시작 흐름

앱 실행 시 단 한 번 실행되는 초기화 흐름입니다.

```
앱 실행
  │
  ▼
[알고리즘 18] 기기 ID 생성
  localStorage에 fruitbox_device_id 존재 여부 확인
  → 없으면 UUID v4 신규 생성 후 저장
  → 있으면 기존 ID 반환
  │
  ▼
[알고리즘 17] localStorage 기록 불러오기
  fruitbox_best_{difficulty} 키로 난이도별 최고 기록 조회
  → 없으면 0 반환
  │
  ▼
[알고리즘 19] 티어 판정
  최고 기록 점수를 구간별 비교 (브론즈 ~ 챌린저)
  → 티어 이름 + 색상 반환
  → 시작 화면에 표시
  │
  ▼
난이도 선택 (쉬움 / 보통 / 어려움)
  → 난이도 버튼 클릭 시 해당 난이도 최고 기록으로 티어 즉시 갱신
  │
  ▼
게임 시작 버튼 클릭 → [다이어그램 2]로 이동
```

**포함 알고리즘**: 18 기기 ID 생성 → 17 localStorage 기록 저장 → 19 티어 판정

---

## 다이어그램 2 — 게임 진행 루프

게임 중 매 프레임 반복되는 핵심 상호작용 흐름입니다.

```
게임 시작
  │
  ▼
[알고리즘 1] 보드 초기화
  10×17 셀에 1~9 난수 배정
  점수 / 타이머 / 아이템 개수 / 플래그 초기화
  │
  ▼
[알고리즘 11] 렌더링 루프 시작 (매 프레임 반복)
  requestAnimationFrame → render() → updateHud()
  │
  ▼
[알고리즘 2] 드래그 선택
  mousedown → 시작 좌표 기록
  mousemove → 끝 좌표 갱신 (매 프레임 화면에 반영)
  mouseup / mouseleave → 드래그 종료
  │
  ▼
[알고리즘 10] 드래그 색깔 변경
  sumRegion 호출 → 합 계산
  합 = 10    → 초록색 (match)
  0 < 합 ≠ 10 → 빨간색 (invalid)
  합 = 0     → 기본색
  │
  ▼
[알고리즘 3] 합산 판정
  선택 영역 내 숫자 합산 (removed / isItem 제외)
  합 ≠ 10 → return 0 (제거 안 함)
  합 = 10 → 다음 단계
  │
  ▼
[알고리즘 4] 사과 제거
  영역 내 셀 removed = true 처리
  제거 셀 수만큼 점수 반영
  → 10% 확률로 [다이어그램 3] 아이템 스폰 진행
  │
  ▼
게임오버? ── Yes ──→ [다이어그램 5]로 이동
  │ No
  ▼
렌더링 루프로 복귀 (반복)
```

**포함 알고리즘**: 1 보드초기화 → 11 렌더링루프 → 2 드래그선택 → 10 색깔변경 → 3 합산판정 → 4 사과제거

---

## 다이어그램 3 — 아이템 흐름

아이템 생성부터 각 아이템 효과 적용까지의 흐름입니다.

```
사과 제거 완료 (다이어그램 2에서 진입)
  │
  ▼
[알고리즘 7] 아이템 스폰 판정
  random(100) < 10 → 10% 확률 판정
  실패 → 종료
  성공 → 제거된 셀 목록 중 랜덤 1칸 선택
         rand() % 2 → BOMB(50%) / CLOCK(50%) 결정
         해당 셀을 아이템 셀로 설정
  │
  ▼
아이템 클릭 or 사용 대기
  │
  ├─── 보드 위 아이템 클릭
  │       │
  │       ├─ [알고리즘 5] 폭탄 효과
  │       │   상하좌우 4방향 탐색
  │       │   보드 범위 내 셀 removed = true
  │       │   score += 5
  │       │
  │       └─ [알고리즘 6] 시계 효과
  │           timeLeft += 5
  │           (상한선 없음)
  │
  └─── 인벤토리 아이템 사용
          │
          ├─ [알고리즘 8] 힌트(돋보기)
          │   가로 인접 쌍 탐색 → 합 10 위치 발견
          │   미발견 시 세로 인접 쌍 탐색
          │   hintTimer = 3 → 1초마다 감소 → 0이면 강조 해제
          │
          └─ [알고리즘 9] 숫자 변환
              changeMode = true → 배너 표시
              다음 셀 클릭 → value = 1로 변경
              아이템 개수 차감, changeMode = false
```

**포함 알고리즘**: 7 아이템스폰 → 5 폭탄 / 6 시계 / 8 힌트 / 9 숫자변환

---

## 다이어그램 4 — 타이머 흐름

게임 중 1초마다 독립적으로 실행되는 타이머 및 일시정지 처리 흐름입니다.

```
게임 시작 → setInterval(tick, 1000) 등록
  │
  ▼
[알고리즘 12] 타이머 (매 1초 실행)
  paused or game_over → 건너뜀
  timeLeft > 0 → timeLeft--
  timeLeft = 0 → game_over = true
  │
  ▼
[알고리즘 13] 시간 경고
  timeLeft <= 15 → warn 클래스 추가 (빨간색)
  timeLeft > 15  → warn 클래스 제거
  │
  ▼
일시정지 버튼 클릭?
  │ No → 타이머 반복
  │ Yes
  ▼
[알고리즘 14] 난이도별 일시정지 처리
  │
  ├─ 쉬움: 제한 없이 일시정지 / 재개
  │
  ├─ 보통: pauseCount >= 5 → 불가
  │        pauseCount++ → setInterval로 10초 카운트다운
  │        10초 경과 → resumeGame() 자동 호출
  │        버튼 텍스트: ▶ 재개 (Ns) [n/5]
  │
  └─ 어려움: 버튼 disabled → 아무 동작 없음
```

**포함 알고리즘**: 12 타이머 → 13 시간경고 → 14 난이도별일시정지

---

## 다이어그램 5 — 게임 종료 흐름

타이머가 0이 됐을 때 실행되는 종료 및 재시작 흐름입니다.

```
timeLeft = 0 감지 (다이어그램 4에서 진입)
  │
  ▼
[알고리즘 15] 게임오버 판정
  game_over = true 설정
  clearInterval(timerInterval)
  cancelAnimationFrame(rafId)
  최종 점수 / 최고 기록 화면에 표시
  │
  ▼
[알고리즘 17] localStorage 기록 저장
  score >= getBest(difficulty) 비교
  → 참이면 fruitbox_best_{difficulty}에 덮어쓰기
  │
  ▼
[알고리즘 19] 티어 갱신
  갱신된 최고 기록으로 티어 재판정
  게임오버 화면에 티어 표시
  │
  ▼
버튼 선택
  │
  ├─ 다시 시작
  │     │
  │     ▼
  │   [알고리즘 16] 재시작
  │     모든 상태 변수 초기화 (pauseCount 포함)
  │     C.restart() → 보드 재생성
  │     startTimer() + gameLoop() 재시작
  │     → [다이어그램 2]로 이동
  │
  └─ 처음으로
        → [다이어그램 1]로 이동
```

**포함 알고리즘**: 15 게임오버판정 → 17 localStorage저장 → 19 티어갱신 → 16 재시작
