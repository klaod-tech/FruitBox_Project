# FruitBox 함수 설명

흐름도 및 알고리즘에 사용된 모든 함수를 한 줄로 정리했습니다.

---

## 핵심 개념

- `setInterval(fn, ms)` = 지정한 시간 간격(ms)마다 함수를 반복 실행하는 브라우저 내장 함수로, 게임의 1초 타이머(`C.tick`)와 일시정지 카운트다운을 구현하기 위해 사용된다. 반복을 중단하려면 반환된 ID를 `clearInterval()`에 전달해야 한다.
- `clearInterval(id)` = `setInterval`로 등록된 반복 실행을 중단하는 브라우저 내장 함수로, 게임 종료·재시작·일시정지 해제 시 타이머를 정지하기 위해 사용된다. `setInterval`이 반환한 ID를 인자로 전달해야 정확히 해당 타이머만 중단된다.

---

## 게임 초기화 / 시작

- `getDeviceId()` = 최초 실행 시 기기 고유 ID(UUID)를 생성하거나 기존 ID를 불러오는 함수로, 로그인 없이 기기를 식별하기 위해 사용된다.
- `initBoard()` = 게임 시작 또는 재시작 시 호출되는 함수로, 보드의 모든 셀에 1~9 난수를 배정하고 점수·타이머·아이템 등 상태를 초기값으로 리셋하기 위해 사용된다.
- `startTimer()` = 게임 시작 시 호출되는 함수로, `setInterval`을 등록하여 1초마다 `C.tick()`이 자동 실행되도록 타이머를 시작하기 위해 사용된다.
- `updateStartTier()` = 난이도 버튼 클릭 시 호출되는 함수로, 선택된 난이도의 최고 기록을 기준으로 시작 화면의 티어 표시를 즉시 갱신하기 위해 사용된다.

---

## 게임 루프 / 렌더링

- `gameLoop()` = `requestAnimationFrame`으로 매 프레임 반복 호출되는 함수로, 보드 렌더링·HUD 갱신·게임오버 감지를 처리하기 위해 사용된다.
- `render()` = 매 프레임 캔버스 전체를 초기화하고 모든 셀을 다시 그리는 함수로, 보드의 현재 상태를 화면에 반영하기 위해 사용된다.
- `drawCell(r, c)` = 특정 행·열의 셀 하나를 캔버스에 그리는 함수로, 숫자·제거 여부·아이템 종류·힌트 강조 등을 시각적으로 표현하기 위해 사용된다.
- `updateHud()` = 매 프레임 점수·남은 시간·아이템 개수 등 HUD 요소의 텍스트를 최신 값으로 갱신하기 위해 사용된다.

---

## 입력 처리

- `canvasPos(e)` = 마우스 이벤트의 화면 좌표를 보드의 행·열(r, c) 좌표로 변환하는 함수로, 어떤 해상도에서도 정확한 셀 위치를 얻기 위해 사용된다.
- `addEventListener()` = HTML 요소에 이벤트 리스너를 등록하는 브라우저 내장 함수로, 마우스 클릭·드래그·키 입력 등의 사용자 입력을 감지하기 위해 사용된다.

---

## 게임 로직 (C 객체)

- `C.over()` = 게임 오버 여부를 반환하는 함수로, `gameLoop()`에서 매 프레임 호출하여 게임 종료 시점을 감지하기 위해 사용된다.
- `C.tick()` = `setInterval`로 1초마다 자동 호출되는 함수로, 남은 시간을 1 감소시키고 0이 되면 게임오버 처리를 하기 위해 사용된다.
- `C.pause()` = 일시정지 버튼 클릭 시 호출되는 함수로, 게임의 일시정지 상태를 토글(켜기/끄기)하기 위해 사용된다.
- `C.paused()` = 현재 일시정지 상태인지 여부를 반환하는 함수로, 일시정지 버튼 클릭 시 현재 상태를 확인하기 위해 사용된다.
- `C.restart()` = 재시작 버튼 클릭 시 호출되는 함수로, 보드·점수·타이머 등 게임 상태 전체를 초기화하기 위해 사용된다.
- `C.removeRegion(r1, c1, r2, c2)` = 드래그 종료 시 호출되는 함수로, 선택 영역의 합이 10일 때 해당 사과들을 제거하고 점수를 반영하기 위해 사용된다.
- `C.sumRegion(r1, c1, r2, c2)` = 드래그 중 매 프레임 호출되는 함수로, 선택 영역 내 숫자의 합을 계산하여 합계 표시창에 실시간으로 반영하기 위해 사용된다.
- `C.score()` = 현재 점수를 반환하는 함수로, 게임오버 화면에 최종 점수를 표시하기 위해 사용된다.
- `C.best()` = 현재 난이도의 최고 점수를 반환하는 함수로, 게임오버 화면에 최고 점수를 표시하기 위해 사용된다.
- `C.time()` = 현재 남은 시간을 반환하는 함수로, 타이머 경고 여부를 판단하고 HUD에 시간을 표시하기 위해 사용된다.
- `C.useChange(r, c)` = 변환 아이템 사용 시 호출되는 함수로, 선택한 셀의 숫자를 1로 변경하기 위해 사용된다.

---

## 아이템

- `spawnItemIn(cells)` = 사과 제거 후 10% 확률로 호출되는 함수로, 제거된 셀 목록 중 랜덤 1칸에 폭탄 또는 시계 아이템을 생성하기 위해 사용된다.

---

## 게임 종료 / 상태 전환

- `showGameOver()` = 게임오버 시 호출되는 함수로, 타이머와 렌더링 루프를 정지시키고 최종 점수·티어를 표시한 뒤 게임오버 화면을 띄우기 위해 사용된다.
- `resumeGame()` = 일시정지 해제 시 호출되는 함수로, 카운트다운 타이머를 중단하고 게임 진행 상태로 복귀하기 위해 사용된다.

---

## Store 객체 (데이터 저장/조회)

> `localStorage` = 브라우저에 데이터를 영구적으로 저장하는 공간으로, 탭을 닫거나 브라우저를 재실행해도 데이터가 사라지지 않아 최고 점수·기기 ID 보관에 사용된다.

- `Store.saveBest(diff, score)` = 게임 종료 시 호출되는 함수로, 현재 점수가 기존 최고 점수보다 높을 때만 localStorage에 갱신하기 위해 사용된다.
- `Store.getBest(diff)` = 게임 시작·종료 시 호출되는 함수로, 난이도별 최고 점수를 localStorage에서 불러오기 위해 사용된다.
- `Store.getTier(score)` = 시작 화면과 게임오버 화면에서 호출되는 함수로, 점수 구간에 따른 티어 이름과 색상을 반환하기 위해 사용된다.

## 브라우저 내장 함수

- `Math.random()` = 0 이상 1 미만의 난수를 반환하는 함수로, 난수 배정·아이템 스폰 확률·아이템 종류 결정 등에 사용된다.
- `Math.ceil()` = 소수점을 올림하여 정수를 반환하는 함수로, `Math.random()*9`의 결과를 1~9 정수로 변환하기 위해 사용된다.
- `Math.floor()` = 소수점을 내림하여 정수를 반환하는 함수로, 배열에서 랜덤 인덱스를 구할 때 사용된다.
- `Math.min()` = 주어진 값 중 최솟값을 반환하는 함수로, 드래그 방향에 관계없이 올바른 영역 범위를 계산하기 위해 사용된다.
- `Math.max()` = 주어진 값 중 최댓값을 반환하는 함수로, `Math.min()`과 함께 드래그 영역의 시작·끝 좌표를 정규화하기 위해 사용된다.
- `requestAnimationFrame()` = 브라우저가 다음 화면을 그리기 직전에 함수를 실행하도록 예약하는 함수로, 60FPS 렌더링 루프를 구현하기 위해 사용된다.
- `cancelAnimationFrame()` = `requestAnimationFrame`으로 예약된 다음 프레임 호출을 취소하는 함수로, 게임 종료 및 재시작 시 이전 루프를 완전히 정지하기 위해 사용된다.
- `localStorage.getItem()` = localStorage에서 키에 해당하는 값을 읽는 함수로, 저장된 최고 점수와 기기 ID를 불러오기 위해 사용된다.
- `localStorage.setItem()` = localStorage에 키-값 쌍을 저장하는 함수로, 최고 점수와 기기 ID를 브라우저에 영구 저장하기 위해 사용된다.
- `crypto.getRandomValues()` = 암호학적으로 안전한 난수를 생성하는 브라우저 내장 함수로, UUID 생성 시 예측 불가능한 고유 값을 만들기 위해 사용된다.
- `document.getElementById()` = HTML 문서에서 특정 ID를 가진 요소를 찾아 반환하는 함수로, 게임 화면·HUD·버튼 등 UI 요소에 접근하기 위해 사용된다.
- `classList.toggle()` = 조건에 따라 CSS 클래스를 추가하거나 제거하는 함수로, 합계 표시창 색상 변경 및 타이머 경고 표시를 한 줄로 처리하기 위해 사용된다.
- `classList.add()` = 요소에 CSS 클래스를 추가하는 함수로, 화면을 숨기거나 특정 스타일을 적용하기 위해 사용된다.
- `classList.remove()` = 요소에서 CSS 클래스를 제거하는 함수로, 숨겨진 화면을 표시하거나 특정 스타일을 해제하기 위해 사용된다.
- `getBoundingClientRect()` = 요소의 크기와 화면 내 위치 정보를 반환하는 함수로, 캔버스의 실제 표시 크기를 계산하여 마우스 좌표를 정확히 변환하기 위해 사용된다.
- `ctx.clearRect()` = 캔버스의 지정 영역을 투명하게 지우는 함수로, 매 프레임 보드를 다시 그리기 전에 이전 화면을 초기화하기 위해 사용된다.
- `parseInt()` = 문자열을 정수로 변환하는 함수로, localStorage에서 문자열로 읽어온 점수를 숫자로 변환하기 위해 사용된다.
