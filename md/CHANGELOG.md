# FruitBox 변경점

---

## 버그 수정

| 수정 내용 | 설명 |
|----------|------|
| 게임오버 후 재시작 시 `pauseCount` 미초기화 | normal 난이도에서 일시정지 횟수가 이전 게임에서 누적되던 버그 |
| 제거 조건 `s % 10 === 0` → `s === 10` | 합이 20, 30 등 10의 배수일 때도 제거되던 버그 |
| 더블 아이템(`[x2]`) 전면 제거 | C 터미널 / 웹 양쪽에서 삭제 |

---

## UI 개선

| 항목 | 변경 내용 |
|------|---------|
| 일시정지 오버레이 제거 | 화면을 가리는 오버레이 삭제 → 버튼 텍스트로 상태 표시 (`▶ 재개 (9s) [1/5]`) |
| HUD 버튼 스타일 통일 | 힌트/변환/일시정지/리셋/홈 버튼에 테두리·너비·높이 동일하게 적용 |
| 드래그 색깔 피드백 추가 | 합=10 → 초록, 0<합≠10 → 빨강 |
| 제거된 칸 드래그 하이라이트 | 이미 제거된 셀도 드래그 시 노란 테두리로 선택 범위 표시 |

---

## C 터미널 변경사항

| 항목 | 이전 | 이후 |
|------|------|------|
| 돋보기 단축키 | `Q` | `e` |
| 숫자변환 단축키 | `W` | `w` |
| HUD 표시 | `[Q:n]` | `[E:n]` |
| 더블 아이템 스폰 확률 | BOMB 25% / CLOCK 25% / DOUBLE 50% | BOMB 50% / CLOCK 50% |
