# FruitBox (사과 게임)

Ubuntu 터미널에서 동작하는 ncurses 기반 사과 게임입니다.
10×17 보드에서 합이 10이 되는 사과 영역을 드래그로 선택해 제거하여 점수를 획득합니다.

---

## 프로젝트 구조

```
FruitBox_Project/
├── main.c       전역 변수 정의, 타이머 스레드, 입력 루프, main()
├── board.c      보드 생성, 합산 판정, 사과 제거, 아이템 스폰, 파일 I/O
├── board.h
├── ui.c         ncurses 렌더링 스레드, 마우스 이벤트 처리
├── ui.h
├── apple.h      Apple 구조체, 전역 변수 extern 선언, 게임 상수
├── Makefile
└── data/        점수 저장 파일 (score.dat)
```

---

## 게임 규칙

- 10×17 보드에 1~9 숫자 사과가 무작위 배치됩니다.
- 마우스로 직사각형 영역을 드래그해 사과를 선택합니다.
- 선택 영역 내 숫자의 합이 **정확히 10**이면 해당 사과들이 제거됩니다.
- 제거된 사과 1개당 1점을 획득합니다.
- 제한 시간(120초) 안에 최대한 많은 점수를 획득하는 것이 목표입니다.

## 화면 구성

```
줄 0     FruitBox   SCORE:   ___   BEST:   ___
줄 1     ─────────────────────────────────────────
줄 2     TIME: ___ s
줄 3~22  [ 10×17 보드 ]
줄 24    ITEMS: [E:2]  [W:2]   합계: __/__
줄 26     RESET     [q]종료 [p]일시정지 ...
```

터미널 최소 크기: **72열 × 27줄**

## 특수 아이템

### 보드 위 스폰 아이템 (사과 제거 시 30% 확률로 등장)

| 표시 | 색상 | 효과 |
|------|------|------|
| `[B]` | 빨간색 | 폭탄: 인접 상하좌우 4칸 추가 제거 |
| `[C]` | 청록색 | 시계: 타이머 +5초 |

### 인벤토리 아이템 (HUD에서 보유 개수 표시)

| 표시 | 단축키 | 효과 |
|------|--------|------|
| `[E:n]` | `e` 또는 HUD 클릭 | 돋보기: 합 10이 되는 위치를 3초간 초록색 강조 |
| `[W:n]` | `w` 또는 HUD 클릭 | 숫자 변환: 선택한 사과의 숫자를 1로 변경 |

## 조작 방법

| 입력 | 동작 |
|------|------|
| 마우스 드래그 | 사과 영역 선택 (합=10이면 제거) |
| `p` | 일시정지 / 재개 |
| `q` | 게임 종료 |
| `w` | 숫자 변환 아이템 사용 |
| `e` | 돋보기 아이템 사용 |
| `r` | 재시작 (게임 오버 후) |
| RESET 클릭 | 보드 및 점수 초기화 |

## 기술 스택

| 항목 | 내용 |
|------|------|
| 언어 | C (C11) |
| UI 라이브러리 | ncurses |
| 멀티스레드 | POSIX pthread (렌더링 / 타이머 분리) |

| 렌더링 | wnoutrefresh + doupdate 더블 버퍼링, 30FPS |

# 웹 버전 (docs/)

브라우저에서 바로 실행되는 HTML/JS 버전입니다.
WASM 빌드 없이 Mock 모드로 동작하며, GitHub Pages로 배포됩니다.

---

## 프로젝트 구조

```
docs/
├── index.html      화면 구성 (시작 / 게임 / 게임오버 화면)
├── style.css       스타일
├── game.js         게임 로직 (Mock + WASM 래퍼)
└── game_core.c     추후 Emscripten WASM 빌드용 C 소스
```

---

## 실행 방법

```bash
# Python 로컬 서버 (docs/ 폴더 기준)
python -m http.server 8080 --directory docs
```

브라우저에서 `http://localhost:8080` 접속

## 주요 기능

### 난이도

| 난이도 | 일시정지 |
|--------|---------|
| 쉬움 | 제한 없음 |
| 보통 | 최대 5회 / 1회당 10초 자동 재개 |
| 어려움 | 불가 |

### 아이템

| 아이템 | 효과 |
|--------|------|
| 💣 폭탄 | 클릭 시 인접 4칸 제거 |
| ⏱️ 시계 | 클릭 시 시간 +5초 |
| 🔍 힌트 | 합 10이 되는 위치 강조 (x2 보유) |
| 🔢 변환 | 선택 사과를 1로 변경 (x2 보유) |

### 기록 저장 (localStorage)

| 키 | 내용 |
|----|------|
| `fruitbox_device_id` | 기기 고유 ID (UUID, 최초 1회 생성) |
| `fruitbox_best_easy` | 쉬움 최고 기록 |
| `fruitbox_best_normal` | 보통 최고 기록 |
| `fruitbox_best_hard` | 어려움 최고 기록 |

> 추후 Supabase 연동으로 전체 랭킹 공유 예정 (`Store.syncToServer()`)

### 티어

| 점수 | 티어 |
|------|------|
| 0 ~ 15 | 브론즈 |
| 16 ~ 30 | 실버 |
| 31 ~ 45 | 골드 |
| 46 ~ 60 | 플레 |
| 61 ~ 75 | 다이아 |
| 76 ~ 89 | 마스터 |
| 90 ~ | 챌린저 |

### 키보드 단축키 (게임 화면)

| 키 | 동작 |
|----|------|
| `P` | 일시정지 / 재개 |
| `Q` | 첫 화면으로 복귀 |
| `W` | 숫자 변환 아이템 사용 |
| `E` | 돋보기 아이템 사용 |
| `R` | 보드 재시작 (게임 중 언제든 가능) |
